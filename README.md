# pwa-adventure-countdown

A standalone Progressive Web App (PWA) — installable on Android and iOS — that counts down to the next Casablanca adventure.

Spun out of the `jost-business` Nx monorepo as its own dedicated, lightweight app.

---

## What this is

A single-screen Angular PWA showing a live countdown (days / hours / minutes / seconds) to the next trip to Casablanca, Morocco. When the date arrives it switches to a celebration screen. Fully installable from the browser — no app store needed.

---

## Tech stack

| Layer | Choice | Why |
|---|---|---|
| Framework | Angular 21 (standalone, signals) | Familiar, great PWA tooling |
| PWA | `@angular/pwa` | Generates service worker + manifest automatically |
| Build | `@angular/build` (esbuild) | Fast, ~35 KB gzipped output |
| Hosting | GitHub Pages | Free, static, supports custom domains |
| CD | GitHub Actions | Auto-deploys on push to `main` |

## Design

Dark romantic theme — deep wine/purple background, glassmorphism countdown boxes with rose glow, the photo framed with a rose border.

- **Background:** `radial-gradient(#2a0a1e, #0d0610)` — deep dark wine
- **Countdown boxes:** translucent with rose border + glow (`rgba(233,30,99,0.12)`)
- **Values:** `#f8bbd0` (soft rose-light)
- **Seconds:** dimmed separately — feels "ticking" without being distracting
- **Celebration screen:** full-screen, pulsing 💕 heart animation, switches automatically when countdown = 0

## Countdown config

The target date is hardcoded in `src/app/app.ts`:

```typescript
const TARGET = new Date(2026, 7, 16, 16, 5); // August 16, 2026 · 16:05
```

To update for the next trip, just change this line and push — GitHub Actions redeploys automatically.

---

## Notifications

On first load the app requests notification permission. When the user opens the app on the day of the trip and permission was granted, a local push notification fires:

> ✈️ Today is the day!  
> Casablanca is waiting for you both! 💕

Note: background notifications (when app is closed) require a push server. This is client-side only — reliable enough for an app you open on the big day.

## PWA install

**Android (Galaxy / Chrome):** Chrome shows an automatic "Add to Home Screen" banner after the second visit. Also available via the browser menu.

**iOS (Safari):** No automatic prompt on iOS. Instruct the recipient to:
1. Open the URL in **Safari** (not Chrome)
2. Tap the **Share** button (box with arrow)
3. Scroll down and tap **"Add to Home Screen"**
4. Tap **Add**

The app then appears on the home screen like a native app — no browser chrome, dark splash screen, full screen.

---

## Offline support

The Angular service worker (configured in `ngsw-config.json`) caches:
- All app JS/CSS on first visit
- The photo (`assets/images/us.jpeg`)
- The PWA icons

After the first visit the app loads fully offline.

## Deployment

### First time

1. Create a GitHub repo `pwa-adventure-countdown` under the `jost-business` account
2. Set the remote and push:
   ```bash
   git remote add origin https://github.com/jost-business/pwa-adventure-countdown.git
   git push -u origin main
   ```
3. In GitHub: **Settings → Pages → Source → GitHub Actions**
4. Add DNS record: `countdown` CNAME → `jost-business.github.io`
5. In GitHub: **Settings → Pages → Custom domain** → `countdown.jost.business`
6. Enable "Enforce HTTPS"

### Every update after that

Just push to `main` — GitHub Actions builds and deploys in ~60 seconds.
